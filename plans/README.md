## Findings considered and rejected

- Rendering removed lines inline as full red lines in the normal editor: not
  possible with the stable VS Code extension API (no view zones). Replaced by
  a red marker + `−N` badge + hover + "Open diff" trigger.
- VS Code quick-diff gutter (`registerQuickDiffProvider`): not in the stable
  API; the `SourceControl.quickDiffProvider` route would add a second, empty
  source-control entry to the SCM view. Not used.
- Running `git diff` per keystroke for the overlay: replaced by an in-process
  line diff of baseline text vs. the live editor buffer, which also stays
  correct for unsaved edits.
- Opening every review file automatically at startup by default: opt-in via
  `gitAxon.autoOpenFiles` instead, because it would open dozens of tabs on
  every window load.
